# PawPilot

宠物健康饮水喂食站的交互原型项目，面向家庭养宠用户，帮助主人查看饮水、进食和设备状态。

## Features

- 定时投喂与立即投喂反馈
- 饮水水位、粮仓余量和碗底称重数据
- 缺水、断粮和摄入异常状态提醒
- 自动补水与事件日志
- 可拖动旋转的 3D 设备结构预览
- 暖宠生活、极简深色、运营台白色三套视觉主题
- 响应式布局，支持桌面端和移动端预览

## Demo flow

Click `立即投喂` to see the feeding state update. Click `模拟缺水`, then `自动补水`, to see the alert and recovery flow. Click `模拟摄入异常` to preview the low-intake alert.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.
